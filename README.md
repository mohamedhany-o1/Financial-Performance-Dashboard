# Financial Performance Dashboard

A Power BI dashboard analyzing revenue, cost, gross profit and net profit, with year-over-year (YOY) comparisons.

## Key features
- Revenue, cost, gross profit and net profit KPIs
- Year-over-year (YOY) measures built with DAX
- Breakdown by channel, region, segment and department

## Tools
Power BI, DAX
